# CounterModule

## Purpose
Runs named counters in either direction and calls each caller back once a second while they last.

## Concepts
countdown, count up, timer, named counter, tick, time source, ICounterService, ITimeSource

## Decisions
- **One step shipped, `ICounterService.Commands.Stop(id)`.** Starting a counter takes a start time
  and the callbacks the caller keeps, so it stays a call from the game's own Command; stopping one
  is a fixed step of a flow, the id given at the binding. `ITimeSource.Prepare` would be a boot
  step too, but the time source is bound inside the module and a step from another context could
  not inject it.
