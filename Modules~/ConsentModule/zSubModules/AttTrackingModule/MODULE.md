# AttTracking

## Purpose
The App Tracking Transparency plug for the Consent module: the iOS tracking prompt behind
`ITrackingProvider`, compiled only when Unity's iOS 14 Advertising Support package is in the project.

## Concepts
ATT, App Tracking Transparency, IDFA, iOS tracking prompt, ATTrackingStatusBinding,
NSUserTrackingUsageDescription, FLOWIOC_IOS_SUPPORT

## Using it
1. `com.unity.ads.ios-support` in the manifest, from Unity's registry.
2. The usage description in the Xcode project's Info.plist (`NSUserTrackingUsageDescription`);
   iOS refuses the prompt without it.
3. `ConsentServiceRoot` > Sub Context Types > Add > `AttTrackingServiceContext`, AutoSetup on,
   beside the consent form's plug.

## Decisions
- **A second socket, not part of the form's plug.** The consent form and the tracking prompt come
  from different SDKs, so each has its own plug and either can be swapped alone.
- **Asked once.** A status already decided is answered without the prompt; only
  `NOT_DETERMINED` shows it. Off an iPhone the answer is `NotApplicable`.
- **Answers come back on the main thread they were asked from**, whatever thread iOS calls back on.

## Known gaps
- Compiled against iOS 14 Advertising Support 1.3.0 in FlowIoC-dev on 2026-11-25, and run in the
  Editor, where it answers `NotApplicable`. Not yet run on an iPhone.
- The Info.plist description is not written for you.
